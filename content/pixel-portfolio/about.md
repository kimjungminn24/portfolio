## 프로젝트 소개

포트폴리오를 만들 때마다 프레임워크와 빌드 환경을 설정하는 과정이 번거롭다고 생각했습니다.

그래서 별도 빌드 과정 없이 정적 호스팅에 바로 배포할 수 있는 포트폴리오 템플릿을 만들었습니다.

프로젝트 목록과 상세 내용은 JSON과 Markdown으로 관리하고, 작은 클라이언트 라우터가 이를 화면에 표시합니다.

## 주요 특징

- 데이터 관리: `data/portfolio.json`에서 프로젝트 정보를 관리하고 `content/` 아래 Markdown 파일로 상세 내용을 작성합니다.
- 테마 설정: 색상, 글꼴, 모서리, 그림자를 CSS 변수로 관리합니다.
- 화면 전환: 버튼 하나로 240p와 4K 화면을 전환할 수 있습니다.
- 데이터 검사: `npm run check`로 중복 ID, 존재하지 않는 파일, 잘못된 날짜 등을 확인합니다.

현재 보고 있는 이 포트폴리오도 해당 템플릿으로 제작했습니다.
