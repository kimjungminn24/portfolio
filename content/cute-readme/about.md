## 프로젝트 소개

GitHub 프로필 README를 단순한 텍스트 대신 작은 픽셀 공간처럼 꾸밀 수 있도록 만들었습니다.

미니룸 에디터, 블록 기반 README 빌더, 링크 뱃지, 저장소 카드, 기여자 그래프 등 여러 도구를 하나의 서비스에 모았습니다.

## 주요 기능

- 미니룸 에디터: 블록을 배치해 나만의 픽셀 공간 구성
- README 빌더: 블록을 추가하고 드래그해 원하는 순서로 배치
- 링크 뱃지: 프로필에 사용할 링크 요소 생성
- 저장소 카드: GitHub 저장소 정보를 카드 형태로 표현
- 기여자 그래프: GitHub 활동을 시각적으로 표현

완성된 결과물은 `Download README.md`를 통해 이미지와 함께 ZIP 파일로 내보낼 수 있습니다.
