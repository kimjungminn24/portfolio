## 문제

기존 통계 API 는 요청마다 모든 데이터를 실시간으로 계산했어요. 그 결과 메인 페이지에 트래픽이 몰릴 경우 평균 **14,755ms** 의 응답 지연이 발생했어요.

## 해결

1. `@Scheduled` 와 **ShedLock** 을 활용해 스케줄 기반 집계 방식을 도입했어요. 여러 인스턴스에서 같은 집계가 중복 실행되지 않도록 ShedLock 으로 잠금을 걸었어요.
2. 계산된 결과는 **별도 테이블에 저장**해서 조회 시점의 부하를 분산했어요.
3. 집계 로직에는 `parallelStream()` 을 적용해 병렬 처리로 속도 개선도 시도했어요.

## 성과

평균 응답 시간이 **1,011ms** 로 단축되었어요. 기존 대비 **14배 이상** 성능이 향상되었어요.
