## 문제

누군가 서버로 부하 테스트를 진행해 **실제 서비스가 다운되는 상황**이 발생했어요. Nginx 로그를 확인해 보니 `.env` 등 민감 파일에 대한 악의적인 요청도 섞여 있었어요.

## 해결

### 요청 차단

- **Badbot-blocker** 와 **rate limiting** 을 설정해 악의적인 요청을 제한했어요.
- **Fail2ban** 을 활용해 로그 기반으로 반복적인 악성 요청을 차단했어요.
- 서버 버전을 숨기고, `.env` 와 `.git` 관련 숨김 파일 요청을 차단했어요.

### 모니터링

- 프리티어 서버 환경을 고려해 서버에 부담이 적은 **Promtail + Grafana Cloud** 조합으로 로그를 수집했어요.
- **Slack 알림**을 설정해 서버 상태와 보안 이벤트를 실시간으로 받아 보고 있어요.

```
sum by(type) (
  count_over_time(
    {job="nginx"} |= "/api/decors/search"
    | regexp "type=(?P<type>[^& ]+)" [24h]
  )
)
```

> Grafana 에서 검색 API 로그를 데코 타입별로 집계하는 쿼리. 어떤 데코가 많이 검색되는지도 같이 보여요.

## 성과

악의적 요청과 반복적인 공격을 **차단**하고, 실시간 모니터링으로 **서비스 안정성을 확보**할 수 있었어요.
