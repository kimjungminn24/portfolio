## 서비스 소개

피크민 블룸(Pikmin Bloom)은 실제 지도를 이동하며 모종을 수집하고 피크민을 키우는 위치 기반 게임입니다. 모종을 획득한 장소의 유형에 따라 영화관, 카페, 편의점 등 다양한 데코 피크민을 얻을 수 있습니다.

### 단독 스팟이란?

특정 장소에서 하나의 데코 유형만 등장하는 장소를 단독 스팟이라고 합니다.

예를 들어 어떤 편의점에서 탐지기를 사용했을 때 편의점 데코 모종만 등장한다면 해당 장소를 편의점 단독 스팟으로 볼 수 있습니다.

## 왜 만들었나

기존 단독 스팟 정보는 주로 카페 게시글이나 지도 좌표, 스크린샷 형태로 공유되고 있었습니다. 정보를 찾으려면 여러 게시글을 확인해야 했고, 위치가 정확한지 또는 아직 유효한 정보인지 판단하기도 어려웠습니다.

원하는 지역과 데코 유형을 기준으로 장소를 검색할 수 있고, 유저들이 직접 정보를 등록하고 검증할 수 있는 공간이 필요하다고 생각했습니다.

## 주요 기능

### 1. 단독 스팟 등록

사용자가 지도에서 원하는 위치를 선택하거나 현재 위치를 기반으로 새로운 스팟을 등록할 수 있습니다.

### 2. 지도 기반 검색

지역을 선택하고 카페, 영화관, 편의점 등 데코 유형을 필터링해 원하는 장소를 찾을 수 있습니다.

### 3. 유저 피드백

새로운 데코가 출시되면 기존 스팟의 단독성이 달라질 수 있습니다. 유저들이 의견을 남겨 정보를 검증하고 변경 사항을 공유할 수 있도록 구성했습니다.

### 4. 의견 제출

GitHub Issues를 통해 오류와 개선 의견을 받고 있습니다. 검색 결과 문구 개선이나 지도 확대 오류 등 실제 사용자의 의견을 서비스에 반영하고 있습니다.

## Claude Code와 함께 운영하기

2026년 10월부터는 Claude Code와 함께 서비스를 개선하고 있습니다. 작업 단위를 PR로 나누고, 변경 내용을 직접 검토한 뒤 릴리스 PR로 묶어 배포합니다. 지금까지 25개의 PR을 이 방식으로 반영했습니다.

- 화면: 지도 중심 메인 화면 개편, 모바일 하단 시트, 접근성(글자 대비, 키보드 조작)
- 성능: 첫 화면 로딩 최적화, 웹폰트 서브셋, 애널리틱스 지연 로드
- 기능: 로그인 없이 등록·피드백, 번체 중국어 지원, 요청 제한(429) 안내
- 인프라: systemd 서비스 전환, 헬스체크 실패 시 자동 되돌리기

혼자 운영하다 보니 미뤄 두었던 작업이 많았는데, 구현 속도가 빨라지면서 사용자 의견을 반영하는 주기를 줄일 수 있었습니다.
